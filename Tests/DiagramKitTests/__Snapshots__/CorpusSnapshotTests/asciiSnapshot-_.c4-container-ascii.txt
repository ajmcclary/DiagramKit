Container diagram for Internet Banking System
=============================================
  • E-Mail System — external_system
  • Customer — person
  • Mainframe Banking System — external_system
  [Internet Banking]
    • Single-Page App — container (JavaScript, Angular)
    • Web Application — container (Java, Spring MVC)
