## Known issues

- **Bundled Noto fonts never register under SwiftPM.** The resource bundle
  carries the fonts flattened at the root (`NotoSans-Regular.otf`) while
  `DiagramFontRegistry.registerBundledFontsIfNeeded()` probes
  `Fonts/noto-sans/…` and `Resources/Fonts/noto-sans/…`, so registration
  misses and all rendering silently uses system-font fallbacks. Snapshot
  determinism is unaffected (same fallback everywhere), but the bundled-font
  guarantee is not currently exercised. Fixing the lookup invalidates every
  image baseline; deferred deliberately.

## Known caveats

- `Scripts/bootstrap-smoke-check.sh` runs every gate and aggregates failures
  (no fail-fast); it exits non-zero if any gate reported failure.
- `Scripts/linux-check.sh` environment skips: no `docker`/`podman`, a
  runtime that is installed but not usable, or `SKIP_LINUX_CHECK=1`.
- The full `swift test` corpus parameterized run can hit the documented
  signal-10; chunked `SNAPSHOT_DIAGRAM_IDS` execution remains the recording
