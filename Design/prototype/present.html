act ii · the boundary Slide IV of XII

Where authentication lives

The SDK terminates traffic at the edge gateway, but identity belongs to the Auth API service — not the gateway, not the app shell. This boundary is the contract we'll defend tonight.

  • SDK — issues login intents, never holds long-lived tokens.
  • Edge — terminates TLS & rate-limits. Stateless.
  • Auth API — sole authority on session & MFA state.
  • Token Svc — vaulted secrets, short-lived JWTs.
