Sharing & permissions

How Engineering shares diagrams — internally and externally. Set the workspace defaults, gate external sharing on approved domains, enforce SSO, and tune the lifecycle of share links. Per-diagram overrides remain available where policy allows.
⚷ Admin · affects all of Engineering

Default visibility & roles

new diagrams in Engineering
Default visibility for new diagrams Where new diagrams land before anyone shares them. Private by default is the safe choice — collaborators are invited explicitly.
Default role for new collaborators Pre-fills the role selector in the Share dialog. People can still override on a per-invite basis.
Confirm before broadening access Show a confirmation when an action moves a diagram from private → shared, internal → external, or grants edit to someone who currently can only view.
Allow diagram-specific permission overrides Owners can override workspace defaults on individual diagrams.

External sharing

Studio feature
Studio plan feature Co-editing collaboration and external sharing are part of the Studio plan. Engineering is on Studio plan — external sharing is available.
External sharing When enabled, members can invite collaborators with email addresses outside the workspace. External viewers do not count against editor seats.
Approved external domains Only people with email at these domains can be invited as external collaborators. Wildcards like *.partner.io are supported.
@partner-co.io @enterprise.dev
Warn before externally sharing Show a confirmation banner inside the Share dialog whenever an invite recipient is outside Engineering.
Require sign-in for external viewers External viewers must authenticate before they can open an Editor link. Anonymous SVG embeds remain accessible per the link's own setting.
Notify owner on external share Email the diagram owner whenever a new external collaborator gains access.

Editor & SVG link lifecycle

Default Editor-link expiration How long a freshly created Editor link is valid before it must be regenerated. Owners can always shorten or revoke individually.
Default SVG-link mode Live links auto-update when the source diagram changes. Snapshot links freeze the diagram at its current state.
Allow password-protected links Owners may add a passphrase to Editor or SVG links. Passwords are hashed at rest and never appear in audit logs.
Auto-revoke unused links If a share link has not been opened in 90 days, revoke it automatically and notify the owner.
2 active workspace-wide link policies External SVG links must include the workspace watermark · Editor links to private diagrams cannot be regenerated by non-owners. Review all policies →

SSO & secure access

Enterprise feature
Enterprise feature SSO enforcement requires an Enterprise plan. Engineering is on Studio plan. Upgrade to Enterprise →
Require SSO for all members Block password sign-in for anyone in the workspace. SSO providers: Okta · Google Workspace · Azure AD.
Block share links from bypassing SSO Editor and SVG links to private diagrams reject requests that don't carry a valid SSO session.
